#  AI Study Assistant

## Overview

AI Study Assistant is a desktop learning application built using Python and Tkinter. The application helps students learn academic topics, revise concepts, and assess their understanding through interactive quizzes.

The goal of this project is to provide a simple and user-friendly study platform where learners can explore different subjects, read topic explanations, take quizzes, and track their performance.

---

## Features

###  Study Topics

Students can select a subject and explore important topics with detailed explanations.

###  Interactive Quizzes

Each subject contains quizzes with multiple difficulty levels:

* Easy
* Medium
* Hard

###  Quiz Timer

Questions are timed to encourage quick thinking and improve assessment accuracy.

###  Score Tracking

Quiz scores are stored and can be viewed later through the score history feature.

### Performance Feedback

The application provides feedback based on quiz performance.

###  Graphical User Interface

Built with Tkinter to provide a clean and easy-to-use desktop experience.
